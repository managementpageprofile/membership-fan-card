# MFC — Membership Fan Card
Upload `index.html`, `style.css`, and `script.js` to your GitHub Pages repository.

## Email and celebrity photo upload
The request form uses Formspree and `multipart/form-data`, so the uploaded celebrity photo is included with the submitted request.

1. Create a Formspree form and set your destination email.
2. Copy its form endpoint/ID.
3. In `index.html`, replace `YOUR_FORM_ID` in `https://formspree.io/f/YOUR_FORM_ID`.
4. Commit the three files to GitHub and enable GitHub Pages.

Before launch, make sure celebrity participation/branding is genuinely authorized and that your privacy, payment, refund and terms information accurately describes your real service.
